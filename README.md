# web_project2025
For the consolidation project, I build another web. This time I include many new skills into the project. This web is also a personal portfolio website designed to showcase different aspects of my life and academic journey. The site is divided into several sections: About Me, Experience, My School. Each part offers insight into my educational background, personal interests, and professional experiences. And each part has separate html other than my previous web.

![image](https://github.com/user-attachments/assets/f0d2249b-2e9d-4fe6-8970-1d2f93dbf72a)

In the first page, you can find a automatically changing photo part, which show my pictures and some words that described me. At the top of the web you can find a bar which include my email and CV download in the left part, and a navigation part in the right where you can click to jump to another page. When you sliding down the page, the color of the bar will change from black with transparency to white which make the web more readable.
